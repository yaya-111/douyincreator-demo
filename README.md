# DBTI：是谁动了我的外卖？

> 赛道一｜互动空间 | 移动端互动推理游戏

## 快速体验

直接在浏览器中打开 `index.html` 即可开始游戏，无需安装任何依赖。

推荐使用手机浏览器或 Chrome DevTools 移动端模拟器（宽度 ≤ 560px）获得最佳体验。

## 项目概述

一款发生在大学宿舍的互动推理游戏。A 栋一层外卖架上，一份蜂蜜芥末炸鸡在 21:47 神秘消失。四名嫌疑人都曾在案发前后出现在附近——你需要在 120 秒内找出真凶。

## 玩法说明

- 初始 4 行动力（AP）
- 查看监控 / 宿舍走访 / 盘问嫌疑人：各消耗 1 AP
- 突击审讯：消耗 2 AP
- AP 耗尽后可通过小游戏补充
- 收集证据后进行最终指认

## 技术实现

- **单文件架构**：所有资源（HTML/CSS/JS/图片）内联在一个文件中
- **纯前端实现**：零外部依赖，Vanilla JavaScript
- **响应式设计**：移动端优先，适配各种屏幕尺寸
- **离线可用**：图片 Base64 编码，无网络请求
